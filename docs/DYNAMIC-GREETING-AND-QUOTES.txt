LifeOS v1.4 — Dynamic dashboard greeting and quote

Greeting: follows the device local clock: Good morning before 12:00, Good afternoon from 12:00 to 17:59, and Good evening from 18:00 onward. The greeting is localized in English, Spanish, French, German and Arabic.

Daily quote: selected locally from an embedded quote bank using the date. It remains stable during the same local day, changes on the next day, works offline, and is localized in all five supported languages. The bank generates 365 distinct daily combinations (20 openings × 20 follow-up lines, with 365 date positions before cycling).

No user data is changed by this feature. No network request is made.
